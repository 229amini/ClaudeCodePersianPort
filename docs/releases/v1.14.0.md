## کلاد فارسی ۱.۱۴.۰: چند حساب، ورود از داخل پنجره

این نسخه هر دو میان‌بر را نصب می‌کند: **کلاد فارسی ۱.۱۴.۰** و **کلاد فارسی — ترمینال ۰.۱۴.۰**.

### تازه‌ها
- **ورود از داخل پنجره:** دیگر برای ورود به حساب Claude به ترمینال نیازی نیست. اگر وارد نشده باشید، پنجره خودش کارت ورود را باز می‌کند. مرورگر باز می‌شود، «Authorize» را می‌زنید و تمام. اگر مرورگر باز نشد، کدی را که صفحهٔ ورود نشان می‌دهد در کارت بچسبانید. `/login` نشان می‌دهد با کدام حساب وارد شده‌اید و `/logout` از حساب خارج می‌شود.
- **چند حساب Claude:** هر حساب را یک بار با «افزودن حساب دیگر» وارد کنید. بعد از آن، جابه‌جایی بین حساب‌ها یک کلیک است و ورود دوباره لازم ندارد. مهارت‌ها، تنظیمات، حافظه و گفتگوهای قبلی برای همهٔ حساب‌ها یکی است. گفتگویی که وسط جواب دادن باشد، اول جوابش را تمام می‌کند.
- **وقتی به سقف مصرف می‌رسید**، زیر پیام سقف برای هر حساب دیگر دکمهٔ «ادامه با …» می‌آید. با زدن آن، کار با آن حساب از همان‌جا ادامه پیدا می‌کند. این دکمه برای سقف هفتگی هم کار می‌کند. پنل مصرف (حلقهٔ ◔) هم نشان می‌دهد سقف‌ها مال کدام حساب است.
- **«حساب‌ها» و «سرورها» در نوار کناری.** با «سرورها» (آزمایشی) کلاد روی یک سرور لینوکسی کار می‌کند و پنجره روی رایانهٔ شماست. این بخش هنوز روی همهٔ حالت‌ها آزمایش نشده است؛ اگر جایی درست کار نکرد، خبرمان کنید. برای افزودن سرور فقط نشانی و نام کاربری لازم است. رمز سرور یک بار پرسیده می‌شود و ذخیره نمی‌شود. نصب و به‌روزرسانی برنامه روی سرور هم از همان‌جا انجام می‌شود (جزئیات در [نسخهٔ ترمینالی ۰.۱۴.۰](https://github.com/229amini/ClaudeCodePersianPort/releases/tag/terminal-v0.14.0)).

- **سرورها در زبانه:** «باز کردن» سرور را در یک زبانه بالای همین پنجره باز می‌کند، کنار «این رایانه»، مثل زبانه‌های Notepad یا VS Code. با کلیک یا Ctrl+PageUp و Ctrl+PageDown بین زبانه‌ها جابه‌جا می‌شوید و کار روی سرورهای دیگر ادامه پیدا می‌کند. نقطهٔ کنار نام هر سرور نشان می‌دهد کلاد مشغول کار است، جوابی آماده دارد یا اتصالش قطع شده است. اتصال قطع‌شده خودش دوباره وصل می‌شود. دکمهٔ ⧉ همان سرور را در پنجرهٔ جدا باز می‌کند. زبانه‌های باز دفعهٔ بعد سر جایشان هستند.

### رفع اشکال
- **به‌روزرسانی Claude Code از داخل پنجره:** Claude Code زیر این برنامه خودش را به‌روز نمی‌کرد و روی بعضی کامپیوترها با پیام «does not support this model» متوقف می‌شد. حالا برنامه هر بار که باز می‌شود به‌روزرسانی را بررسی می‌کند (روی سرور روزی یک بار). اگر آن پیام را دیدید، دکمهٔ «به‌روزرسانی Claude Code» زیر همان پیام را بزنید و پیامتان را دوباره بفرستید.
- اگر Edge کامپیوتر قدیمی باشد (پیش از نسخهٔ ۱۱۴)، پنجره بی‌ظاهر و به‌هم‌ریخته باز می‌شد. حالا نصب‌کننده نسخهٔ Edge را بررسی می‌کند و در صورت نیاز آن را به‌روز می‌کند. برای کامپیوتری که اینترنتش محدود است، فایل نصب Edge را می‌شود کنار نصب آفلاین گذاشت (`payload\README.txt`).
- **دستورهای `!`:** کلاد حالا همان لحظه دربارهٔ خروجی دستور جواب می‌دهد، مثل Claude Code در ترمینال. پیش از این، خروجی تا پیام بعدی شما منتظر می‌ماند.
- در نسخهٔ پنجره‌ای، وقتی دو گفتگو باز است و «۲» را انتخاب می‌کنید، ستون دوم دیگر خالی نمی‌ماند و گفتگوی باز دوم در آن نشان داده می‌شود.

### نصب در سه قدم
۱. فایل **Source code (zip)** پایین همین صفحه را دانلود کنید و از حالت فشرده خارج کنید.
۲. روی `persian-claude-gui\setup.bat` دوبار کلیک کنید.
۳. میان‌بر «کلاد فارسی» یا «کلاد فارسی — ترمینال» را از دسکتاپ باز کنید.

اگر نسخهٔ قبلی را دارید، همین سه قدم کافی است. نصب‌کننده نسخهٔ قبلی را به‌روز می‌کند و گفتگوها و تنظیمات شما سر جایشان می‌مانند.

پیش‌نیاز: ویندوز ۱۰ یا ۱۱ و یک حساب Claude که Claude Code با آن کار کند. اگر پایتون و Claude Code نصب نباشند، نصب‌کننده خودش نصبشان می‌کند.

**English:** Web edition 1.14.0; the download also installs the terminal edition 0.14.0. **New:** sign in from the window (`claude auth login` behind a Persian card; browser approval or a pasted code; `/login`, `/logout`); several Claude accounts, each added once and switched in one click with skills, settings, memory and history shared; at a usage wall (five-hour or weekly) a «continue on …» button per other account carries the work on there; the usage panel names the active account; «Accounts» and «Servers» in the sidebar — Linux servers over SSH (experimental) added with an address and a user, the password asked once and never stored, the app installed or updated there from the window; each server opens as a tab along the top of this window. **Fixed:** Claude Code never updated itself under the window (`-p`), so a model it did not know failed with "does not support this model": the window now runs `claude update` at start (daily on a server) and offers a button under that error; setup updates an Edge older than 114, which drew the window unstyled (an offline payload can carry the Edge MSI); a `!` command's output now goes to Claude at once and gets an answer, as in the terminal, instead of waiting for the next message; the web edition's «2» split now shows the second open conversation instead of a blank column.
