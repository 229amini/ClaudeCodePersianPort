## کلاد فارسی ۱.۱۴.۰: چند حساب، ورود از داخل پنجره

این نسخه هر دو میان‌بر را نصب می‌کند: **کلاد فارسی ۱.۱۴.۰** و **کلاد فارسی — ترمینال ۰.۱۴.۰**.

### تازه‌ها
- **ورود از داخل پنجره:** دیگر برای ورود به حساب Claude به ترمینال نیازی نیست. اگر وارد نشده باشید، پنجره خودش کارت ورود را باز می‌کند. مرورگر باز می‌شود، «Authorize» را می‌زنید و تمام. اگر مرورگر باز نشد، کدی را که صفحهٔ ورود نشان می‌دهد در کارت بچسبانید. `/login` نشان می‌دهد با کدام حساب وارد شده‌اید و `/logout` از حساب خارج می‌شود.
- **چند حساب Claude:** هر حساب را یک بار با «افزودن حساب دیگر» وارد کنید. بعد از آن، جابه‌جایی بین حساب‌ها یک کلیک است و ورود دوباره لازم ندارد. مهارت‌ها، تنظیمات، حافظه و گفتگوهای قبلی برای همهٔ حساب‌ها یکی است. گفتگویی که وسط جواب دادن باشد، اول جوابش را تمام می‌کند.
- **وقتی به سقف مصرف می‌رسید**، زیر پیام سقف برای هر حساب دیگر دکمهٔ «ادامه با …» می‌آید. با زدن آن، کار با آن حساب از همان‌جا ادامه پیدا می‌کند. این دکمه برای سقف هفتگی هم کار می‌کند.

### رفع اشکال
- اگر Edge کامپیوتر قدیمی باشد (پیش از نسخهٔ ۱۱۴)، پنجره بی‌ظاهر و به‌هم‌ریخته باز می‌شد. حالا نصب‌کننده نسخهٔ Edge را بررسی می‌کند و در صورت نیاز آن را به‌روز می‌کند. برای کامپیوتری که اینترنتش محدود است، فایل نصب Edge را می‌شود کنار نصب آفلاین گذاشت (`payload\README.txt`).
- در نسخهٔ پنجره‌ای، وقتی دو گفتگو باز است و «۲» را انتخاب می‌کنید، ستون دوم دیگر خالی نمی‌ماند و گفتگوی باز دوم در آن نشان داده می‌شود.

### نصب در سه قدم
۱. فایل **Source code (zip)** پایین همین صفحه را دانلود کنید و از حالت فشرده خارج کنید.
۲. روی `persian-claude-gui\setup.bat` دوبار کلیک کنید.
۳. میان‌بر «کلاد فارسی» یا «کلاد فارسی — ترمینال» را از دسکتاپ باز کنید.

اگر نسخهٔ قبلی را دارید، همین سه قدم کافی است. نصب‌کننده نسخهٔ قبلی را به‌روز می‌کند و گفتگوها و تنظیمات شما سر جایشان می‌مانند.

پیش‌نیاز: ویندوز ۱۰ یا ۱۱ و یک حساب Claude که Claude Code با آن کار کند. اگر پایتون و Claude Code نصب نباشند، نصب‌کننده خودش نصبشان می‌کند.
