## کلاد فارسی، نسخهٔ ترمینالی ۰.۸.۰

دانلودش همان [کلاد فارسی ۱.۸.۰](https://github.com/229amini/ClaudeCodePersianPort/releases/tag/v1.8.0) است و نصب، هر دو میان‌بر را می‌سازد. این صفحه شمارهٔ نسخهٔ ترمینالی را ثبت می‌کند.

### تازه‌ها
- **جستجو و تغییر نام گفتگوها** در نوار کناری.
- **سطر «پرسش‌ها»**، و **«۲ از ۵»** برای درخواست‌های اجازه‌ای که پشت هم می‌رسند.
- **«گفتگوی تازه از اینجا»** زیر هر پیام. شبیه `/rewind` خود کلاد است، با این فرق که گفتگوی قبلی کوتاه نمی‌شود.
- **نمای متمرکز** با <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>F</kbd> یا `/focus`.
- سطح اجازهٔ «خودکار» حالا **«تأیید همه»** نام دارد و نوار وضعیت «تأیید همه روشن» را نشان می‌دهد.

### نصب در سه قدم
۱. فایل **Source code (zip)** پایین همین صفحه را دانلود کنید و از حالت فشرده خارج کنید.
۲. روی `persian-claude-gui\setup.bat` دوبار کلیک کنید.
۳. میان‌بر «کلاد فارسی» یا «کلاد فارسی — ترمینال» را از دسکتاپ باز کنید.

پیش‌نیاز: ویندوز ۱۰ یا ۱۱ و یک حساب Claude که Claude Code با آن کار کند. پایتون و Claude Code را اگر نباشند، نصب‌کننده خودش نصب می‌کند.

**مشکلی دیدید یا پیشنهادی دارید؟** [اینجا بنویسید](https://github.com/229amini/ClaudeCodePersianPort/issues/new/choose). فرم‌ها فارسی‌اند. اگر برنامه به کارتان آمد، یک ⭐ بدهید و آن را برای دوستانتان بفرستید.

> این پروژه مستقل است و به Anthropic وابسته نیست.
