## کلاد فارسی ۱.۸.۰ — نسخهٔ پنجره‌ای

این نسخه هر دو میان‌بر را نصب می‌کند: **کلاد فارسی ۱.۸.۰** و **کلاد فارسی — ترمینال ۰.۸.۰**.

### تازه‌ها
- **جستجوی گفتگوها** در نوار کناری، در همهٔ پروژه‌ها؛ نیم‌فاصله و «ي/ی»، «ك/ک» فرقی نمی‌کنند.
- **تغییر نام گفتگو** از منوی ⋯ — همان نامی که `claude --resume` هم نشان می‌دهد.
- **سطر «پرسش‌ها»**: بعد از جواب دادن به سؤال کلاد، سؤال و جواب شما در گفتگو می‌ماند.
- **«۲ از ۵»** وقتی چند درخواست اجازه پشت هم می‌رسد.
- **«گفتگوی تازه از اینجا»** زیر هر پیام؛ گفتگوی قبلی دست نمی‌خورد.
- **نمای متمرکز** با <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>F</kbd> یا `/focus`: فقط پرسش‌ها و پاسخ‌ها.
- سطح اجازهٔ «خودکار» حالا **«تأیید همه»** نام دارد، تا با حالت Auto خود کلاد اشتباه نشود.

### نصب در سه قدم
۱. فایل **Source code (zip)** پایین همین صفحه را دانلود کنید و از حالت فشرده خارج کنید.
۲. روی `persian-claude-gui\setup.bat` دوبار کلیک کنید.
۳. از میان‌بر «کلاد فارسی» یا «کلاد فارسی — ترمینال» روی دسکتاپ بازش کنید.

پیش‌نیاز: ویندوز ۱۰ یا ۱۱ و یک حساب Claude که Claude Code با آن کار کند. پایتون و Claude Code را اگر نباشند، نصب‌کننده خودش نصب می‌کند.

**مشکلی دیدید یا پیشنهادی دارید؟** [اینجا بگویید](https://github.com/229amini/ClaudeCodePersianPort/issues/new/choose) — فرم‌ها فارسی‌اند. اگر به کارتان آمد، یک ⭐ بدهید و برای دوستانتان بفرستید.
