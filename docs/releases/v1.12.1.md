## کلاد فارسی ۱.۱۲.۱، نسخهٔ پنجره‌ای

این نسخه هر دو میان‌بر را نصب می‌کند: **کلاد فارسی ۱.۱۲.۱** و **کلاد فارسی — ترمینال ۰.۱۲.۱**.

### تازه‌ها
- **ظاهر تازه.** هر دو نسخه را از روی افزونهٔ Claude Code برای VS Code از نو طراحی کردیم: همان اندازه‌ها، همان فاصله‌ها، و رنگ نارنجی کلاد.
- **نوار زیر کادر پیام:** «+» برای پیوست فایل، `@` و سرورهای MCP؛ «/» برای فهرست فرمان‌ها که فارسی و انگلیسی را با هم جستجو می‌کند؛ منوی حالت و منوی مدل. سطح تلاش را در پایین همین دو منو تنظیم می‌کنید.
- **لحن پاسخ** را پیش از اولین پیام از منوی حالت انتخاب کنید. بعد از آن ثابت می‌ماند، چون عوض کردنش کل گفتگو را دوباره و بدون کش می‌خواند.
- **عوض کردن مدل وسط گفتگو** اول از شما می‌پرسد و می‌گوید چقدر از گفتگو دوباره خوانده می‌شود.
- **سقف پنج‌ساعتهٔ مصرف:** اگر وسط کار به آن برسید، پنجره بعد از باز شدن سقف خودش کار را ادامه می‌دهد.
- **دستورهایی که در پس‌زمینه اجرا می‌شوند** تا وقتی کارشان تمام نشده، در پنل کارها دیده می‌شوند.
- **«کپی شناسهٔ گفتگو»** در منوی ⋯ هر گفتگو. با آن می‌توانید همان گفتگو را با `claude --resume` در ترمینال ادامه دهید.
- **درخواست اجازه منتظر شما می‌ماند** و دیگر بعد از دو دقیقه خودبه‌خود رد نمی‌شود.
- گفتگوی قدیمی از آخرین پیامش باز می‌شود و «متوقف شد» بعد از بارگذاری دوباره سر جایش می‌ماند.
- عکس‌های پیوست وقتی هر دو نسخه با هم باز باشند، درست نمایش داده می‌شوند.

### نصب در سه قدم
۱. فایل **Source code (zip)** پایین همین صفحه را دانلود کنید و از حالت فشرده خارج کنید.
۲. روی `persian-claude-gui\setup.bat` دوبار کلیک کنید.
۳. میان‌بر «کلاد فارسی» یا «کلاد فارسی — ترمینال» را از دسکتاپ باز کنید.

پیش‌نیاز: ویندوز ۱۰ یا ۱۱ و یک حساب Claude که Claude Code با آن کار کند. اگر پایتون و Claude Code نصب نباشند، نصب‌کننده خودش نصبشان می‌کند.

**مشکلی دیدید یا پیشنهادی دارید؟** [اینجا بنویسید](https://github.com/229amini/ClaudeCodePersianPort/issues/new/choose). فرم‌ها فارسی‌اند. اگر برنامه به کارتان آمد، یک ⭐ بدهید و آن را برای دوستانتان بفرستید.
